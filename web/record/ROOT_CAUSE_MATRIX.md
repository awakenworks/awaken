# Recording root-cause and causal-test matrix

This matrix is the release record for failures found by real recording. A chapter is not fixed until the root invariant, sibling search, prevention test, and real all-in-one rerun are all closed.

```mermaid
flowchart LR
  A[Unchecked setup mutation] --> B[Missing or stale durable prerequisite]
  C[Non-idempotent fixture] --> B
  D[Same source revision resolves to new bytes] --> E[Duplicate executable publication]
  F[Self-hosted Environment without a live Worker] --> G[Worker lease unavailable]
  B --> H[Session admission or runtime fails]
  E --> I[Registration recovery becomes unhealthy]
  G --> J[Retry and warning amplification]
  H --> K[Recording exceeds budget or proves a false claim]
  I --> K
  J --> K
```
