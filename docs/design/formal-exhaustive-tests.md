# Finite-domain obligations proved by exhaustive tests

Each row was a `#[kani::proof]` harness whose every symbolic input ranges over a closed
enum, a bool, a small integer or an ASCII byte. It is now a `#[test]` that enumerates the
whole domain under nextest on every commit. The source is the authority: the test's
`/// @exhaustive <domain>` line states the domain and its `/// @obligation` lines keep the
ledger mapping (`formal_anchors.py`, `formal_ledger.py`). This list is a snapshot of
2026-11-07; for the current set run `git grep -n -A1 "/// @exhaustive" -- crates`.

The harness had the test's name unless the Harness column says otherwise.
